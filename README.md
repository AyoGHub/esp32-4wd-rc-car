# ESP32 Bluetooth 4WD RC Car

A Bluetooth-controlled RC car controlled by the ESP32 Board

## Features

- Bidirectional drive control for 3 DC motors, steering control for a 4th motor
- L293D H-bridge IC for motor control
- Toggleable rainbow RGB headlight
- Musical buzzer with three programmed songs; a button cycles between the melodies
- Nintendo Joy-Con provides wireless Bluetooth control
- Rechargeable 9 V battery supply

## Hardware

- ESP32
- Nintendo Joy-Con
- L293D motor-driver IC
- Four DC motors
- RGB LED
- Passive buzzer

## Wiring and Power

ESP32 is powered safely via a USB-C cable to a smart device (stable 5 V), while the high-voltage motor system is powered externally using a 9 V battery
